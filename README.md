# 🔧 Basic Electronic Circuits & Applications – Learning & Simulation

This repository contains basic electronic circuits that I (Uri) designed and simulated during my learning journey in electronics, microcontrollers, and embedded systems. The goal is to deeply understand each component's behavior and how to apply them in real-world scenarios.

## 📁 Circuit List

| Folder Name                        | Description                                                  |
|-----------------------------------|--------------------------------------------------------------|
| `normal_LED_control`              | Basic LED circuit using a switch and series resistor         |
| `LED_control_pulldown`            | LED control with a pull-down resistor to stabilize the input |
| `LED_control_with_74hc14_ic`      | Oscillating LED circuit using 74HC14 Schmitt Trigger IC      |
| `blynk_LED_with_ne555n_ic`        | LED blinking using NE555 timer in astable mode               |
| (More coming soon...)  | ...                      |

## 🎯 Goals of This Repo

- Build a solid understanding of **basic ICs and components**
- Practice schematic design and PCB layout
- Use as a reference for quick testing or future projects
- Lay the foundation for more advanced applications (e.g., drone, robot, automation)

## 🔧 Tools Required

- KiCad or EasyEDA for PCB design
- TinkerCAD for simulate
